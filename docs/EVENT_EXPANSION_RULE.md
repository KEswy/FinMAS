# 事件扩充规则 v1（待你过目）

目标：在 2020–2025 窗口内，用**事前、可复现、无泄漏**的规则新增 **+30~50 个事件**，把事件簇从 50 提到 ~80–100，提升统计功效。**红线**：堵死审稿人 5b（事件名内嵌结果）与 5c（行业选择看事后涨跌手挑）。

> 价格数据 `industry_daily.csv`(2019→2025) 已覆盖此窗口，**新增事件不用重拉价格**，只需 (日期, 行业) → `compute_car.py` 自动算 CAR。

---

## 一、事件来源（固定信源清单，事前可查，禁止事后挑）

只从下列**官方/公开日历**取事件，按信源逐条纳入，不按"哪个后来涨跌明显"筛：

| event_type | 固定信源 | 纳入规则 |
|---|---|---|
| monetary_policy | 央行 LPR 月度公告、降准/MLF/OMO 利率变动公告 | 每次有变动的公告日全纳入（LPR 持平的月份不纳入，避免噪声） |
| capital_market_policy | 证监会/交易所规则公告、国常会/政治局涉资本市场表述 | 官方发布日 |
| industry_policy | 国务院/部委行业政策公告（gov.cn） | 政策正式发布日 |
| geopolitical | 重大关税/制裁/冲突的**触发公告日**（新闻通稿日期） | 事件触发日，非市场反应日 |
| market_event | ⚠️ **本轮不新增**（见下文红线） | — |

**为什么 market_event 不新增**：这类事件名天然内嵌涨跌（"黑色星期一…跌7.34%"），是 5b 泄漏源。现有 13 个 market_event 已在论文里做剔除鲁棒检查；**新增只从政策类取**，从源头避开 5b。

## 二、事件命名规则（堵 5b）

`event_name` 必须是**事件日当天即可知的政策/触发描述**，**禁止**任何事后涨跌/结果词。

- ✅ 允许："LPR下调：1年期降10bp至3.45%"、"美国宣布对华加征关税"、"证监会发布程序化交易新规"
- ❌ 禁止："…引发券商大涨"、"…冲击地产"、"…黑色星期一跌7.3%"、"利好/利空X板块"
- **校验**：新增事件名过一遍禁用词表（涨/跌/暴/崩/黑色/利好/利空/受益/重挫/飙…），命中即改写为纯事前描述。

## 三、行业选择规则（堵 5c，最关键）

**不看事后涨跌**。用一张**冻结的"关键词→申万一级行业"映射表**，对**事件名文本**做确定性匹配，命中即纳入该事件的 affected_industries。表事前定死、对所有事件一致、可复现。

| 关键词（出现在事件名） | → 申万一级行业(代码) |
|---|---|
| LPR/降准/利率/货币/流动性 | 银行801780, 非银801790, 房地产801180 |
| 关税/出口/贸易/制裁 | 电子801080, 家电801110, 汽车801880, 机械801890 |
| 半导体/芯片/科技/自主可控 | 电子801080, 计算机801750, 通信801770 |
| 地产/房/按揭/棚改 | 房地产801180, 建材801710, 银行801780 |
| 双碳/新能源/光伏/风电/电 | 电力设备801730, 公用事业801160, 有色801050 |
| 军工/国防 | 国防军工801740 |
| 券商/资本市场/注册制/活跃 | 非银801790, 银行801780, 计算机801750 |

- 一个事件命中多个关键词 → 取并集。
- 命中 0 个 → **该事件不纳入**（宁缺毋滥，避免硬凑）。
- **映射表冻结在代码里**（`scripts/expand_events.py` 的常量），改表=改代码=可审计。

## 四、CAR 与窗口（与现有一致，不变）

- 事件日 t = 公告日；窗口 = t+1…t+5（决策点在 t 收盘，不含事件当天）。
- CAR = 行业5日累计收益 − 沪深300 5日累计收益（简单市场调整，无 α/β）。
- 直接复用 `compute_car.py`，给 (event_date, event_type, event_name, affected_industries) 即出。

## 六、诚实预期（不夸大）

- 50→~85 事件，**firewall 泄漏偏置(已 p=0.029)会更稳**；redistribution **可能**过显著线，但效应小，**不保证**。
- 论文里必须写明："扩充事件按预注册的信源清单 + 冻结关键词-行业映射选取，命名去结果化"——这本身是**答 5b/5c 的方法学加分**，即使功效没到 p<0.05。
- **风险**：若某信源事件太少/映射命中率低，可能只到 +20 而非 +50。届时如实报。
