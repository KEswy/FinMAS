# Data and Results Notice

This repository includes raw financial-market data, event metadata, document-library excerpts, and experiment outputs for research reproducibility. The data is provided as-is for non-commercial research and educational use.

Before redistributing or using this data in production, verify the original source licenses and terms for:

- Shenwan industry daily data (`data/raw/industry_daily.csv`)
- CSI 300 data (`data/raw/hs300.csv`)
- LPR and financing/margin data (`data/raw/lpr.csv`, `data/raw/margin_daily.csv`)
- Industry fundamentals (`data/raw/industry_fundamentals.csv`)
- Event documents and experiment outputs

No real API keys or secrets should be included. If you discover any sensitive information in this repository, report it and remove it immediately.
